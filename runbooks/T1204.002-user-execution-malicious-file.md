# Runbook: User Execution of Script Interpreter from Untrusted Interactive Parent — T1204.002

## Alert Summary
This alert triggers when an interactive user process (`explorer.exe` or archive managers like `7zFM.exe`, `winrar.exe`) executes a Windows script interpreter (`wscript.exe`, `cscript.exe`, `mshta.exe`) passing a target file located in user-writable directories (`Downloads`, `Temp`, `AppData`). This represents the immediate point of malicious attachment execution following phishing delivery.

## Immediate Triage Steps
1. **Analyze Command Line Arguments**: Inspect the script path and parameters passed to `wscript.exe` / `cscript.exe` / `mshta.exe`.
2. **Review Parent Process Tree**: Confirm whether `explorer.exe` spawned the interpreter directly (double-click simulation) or via an archive utility.
3. **Capture Process Lineage**: Identify child processes spawned by the script interpreter (e.g., `cmd.exe`, `powershell.exe`, `rundll32.exe`, `certutil.exe`).
4. **Acquire Script Artifact**: If the script remains in the user folder, capture its SHA-256 hash and submit to sandbox/threat intelligence platforms.
5. **Check Network Activity**: Review network connections initiated by the interpreter or its child processes within 10 minutes of execution.

## Investigation Queries
```kql
// Identify child processes spawned by the script engine
DeviceProcessEvents
| where Timestamp between (datetime({AlertTime}) - 2m .. datetime({AlertTime}) + 30m)
| where DeviceName == "{DeviceName}"
| where InitiatingProcessFileName in~ ("wscript.exe", "cscript.exe", "mshta.exe")
| project Timestamp, DeviceName, FileName, ProcessCommandLine, AccountName
```

## Escalation Criteria
Escalate to **Tier 2 / Incident Response** if:
- Child processes include LOLBins, PowerShell, or process injection tools.
- Network connections to external unknown IP addresses are established.
- Host exhibits persistence creation (Registry Run keys or Scheduled Tasks) shortly after execution.

## Known False Positives
- Internal legacy administration tools or printer setup scripts executing from shared temporary network paths.
- Authorized custom enterprise macros invoking local helper scripts.
