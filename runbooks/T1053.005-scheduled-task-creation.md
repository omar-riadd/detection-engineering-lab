# Runbook: Scheduled Task Creation Executing Script Interpreter or Payload — T1053.005

## Alert Summary
This alert triggers when Windows Security Event ID 4698 (`A scheduled task was created`) records the registration of a new task configured to execute script interpreters (`powershell.exe`, `cmd.exe`, `wscript.exe`) or binaries located in user-writable directories (`C:\Users\Public\`, `C:\Windows\Temp\`, `AppData\Local\Temp`). Adversaries establish scheduled tasks for persistence, privilege escalation, or staged execution of ransomware precursors.

## Immediate Triage Steps
1. **Analyze Task XML Content**: Check `TaskContent` in Event ID 4698 to inspect `<Command>`, `<Arguments>`, and `<UserId>`. Verify if the command string contains obfuscated arguments or network download stubs.
2. **Review User Context**: Identify `SubjectUserName` who registered the task. Is this a local user, domain administrator, or non-administrative account?
3. **Inspect Referenced Binary/Script**: Navigate to the executable path specified in the task action. Calculate file hash (SHA-256), check digital signatures, and submit to sandbox analysis if unverified.
4. **Determine Task Schedule & Triggers**: Check `<Triggers>` in `TaskContent` (e.g., at boot, at logon, or repeating intervals) to understand how the attacker plans to trigger execution.
5. **Check for Immediate Execution**: Query Windows TaskScheduler Event ID 100 (`Task Started`) or Sysmon Event ID 1 (`ProcessCreate`) spawned by `taskeng.exe` or `svchost.exe` matching the task name.

## Investigation Queries
```kql
// Identify scheduled tasks executing script interpreters or user path binaries
SecurityEvent
| where EventID == 4698
| where TaskContent has_any ("powershell", "cmd.exe", "wscript", "cscript", "rundll32", "regsvr32", "Users\\Public", "Temp")
| where not(SubjectUserName in ("SYSTEM", "LOCAL SERVICE", "NETWORK SERVICE"))
| project TimeGenerated, Computer, SubjectUserName, TaskName, TaskContent
```

## Escalation Criteria
Escalate to **Tier 2 / Incident Response (P2/High)** if:
- Task executes base64-encoded PowerShell, downloaded payload, or binary from `C:\Users\Public\` or `%TEMP%`.
- Task was created via remote command execution (WMI, SMB, or PsExec).
- Task payload initiates outbound network connections to unknown IP addresses.

## Known False Positives
- Enterprise systems management tools (Microsoft Intune, SCCM, Tanium) creating temporary remediation tasks.
- Legitimate software installers creating scheduled update checks under standard vendor directories.
