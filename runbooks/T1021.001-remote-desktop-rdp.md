# Runbook: Remote Desktop Protocol (RDP) Inbound Interactive Session — T1021.001

## Alert Summary
This alert triggers when Windows Security Event ID 4624 detects an inbound Remote Interactive logon (LogonType 10) originating from an external or non-loopback network IP address. Adversaries utilize RDP sessions during lateral movement and ransomware staging to gain interactive graphical desktop access, interact with enterprise administration consoles, and manually execute encryption payloads.

## Immediate Triage Steps
1. **Identify Source Client & IP**: Check `IpAddress` and `WorkstationName` in Event ID 4624. Is the source host a designated administrative bastion or an unexpected endpoint?
2. **Review User Context**: Examine `TargetUserName` and `TargetDomainName`. Is this account expected to initiate interactive RDP sessions on this specific workstation or server?
3. **Correlate with RDP Operational Logs**: Check `Microsoft-Windows-TerminalServices-LocalSessionManager/Operational` Event ID 21 (Session logon succeeded) and Event ID 25 (Session reconnection) for source network addresses and session IDs.
4. **Inspect Executed Applications**: Query Sysmon Event ID 1 (`ProcessCreate`) for processes spawned within the newly established RDP user session (`explorer.exe` child processes, command prompts, or PowerShell).
5. **Evaluate Multi-Factor Authentication (MFA)**: Verify whether the RDP gateway enforced MFA or whether direct port 3389 inbound access bypassed security controls.

## Investigation Queries
```kql
// Identify inbound RDP sessions and subsequent process execution
SecurityEvent
| where EventID == 4624 and LogonType == 10
| where not(IpAddress in ("127.0.0.1", "::1", "-"))
| project TimeGenerated, Computer, Account, IpAddress, WorkstationName
| join kind=inner (
    DeviceProcessEvents
    | where Timestamp >= ago(24h)
    | project Timestamp, Computer=DeviceName, FileName, ProcessCommandLine, AccountName
  ) on Computer
| where Timestamp between (TimeGenerated .. TimeGenerated + 30m)
```

## Escalation Criteria
Escalate to **Tier 2 / Incident Response (P2/High)** if:
- RDP session originates from an unauthorized internal subnet, Kali Linux hostname, or external public IP.
- Multiple endpoints establish RDP sessions under the same user credential within a narrow time window.
- RDP session spawns administrative command tools (`cmd.exe`, `powershell.exe`, `vssadmin.exe`, or unapproved executables).

## Known False Positives
- System administrators conducting authorized remote support or maintenance sessions.
- VDI (Virtual Desktop Infrastructure) end-users connecting to pooled virtual desktops.
