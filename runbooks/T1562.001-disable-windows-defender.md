# Runbook: Impair Defenses via PowerShell Set-MpPreference Tampering — T1562.001

## Alert Summary
This alert triggers when PowerShell Script Block Logging (Event ID 4104) or Process Creation (Event ID 1 / 4688) detects execution of `Set-MpPreference` configuring Microsoft Defender protection features to `$false` or disabling real-time monitoring (`-DisableRealtimeMonitoring $true`), behavior monitoring, or script scanning. Adversaries systematically impair local antivirus defenses prior to staging malware loaders or executing ransomware.

## Immediate Triage Steps
1. **Analyze PowerShell Command Line**: Inspect `ScriptBlockText` in Event ID 4104. Identify which protection features were toggled off (`DisableRealtimeMonitoring`, `DisableBehaviorMonitoring`, `DisableScriptScanning`, `DisableIOAVProtection`, or exclusion additions).
2. **Review User & Process Context**: Examine `User`, `Computer`, and `Path`. Was the command executed interactively from an administrator PowerShell console, via an unapproved script, or from a remote service session?
3. **Check for Security Service Tampering**: Check Windows System Event log for service control requests stopping `WinDefend`, `Sense`, or security agent services (`sc stop`, `net stop`).
4. **Identify Surrounding Malicious Artifacts**: Query Sysmon Event ID 11 (`FileCreate`) on the host within 15 minutes of the alert to identify newly dropped tools or ransomware executables that were shielded by the disabled protection.
5. **Immediate Remediation**: Re-enable Microsoft Defender real-time monitoring via administrative PowerShell (`Set-MpPreference -DisableRealtimeMonitoring $false`) and isolate the endpoint.

## Investigation Queries
```kql
// Identify PowerShell script block execution disabling Microsoft Defender
Event
| where Source == "Microsoft-Windows-PowerShell" and EventID == 4104
| where EventData has "Set-MpPreference"
| where EventData has_any (
    "DisableRealtimeMonitoring",
    "DisableBehaviorMonitoring",
    "DisableScriptScanning",
    "DisableIOAVProtection"
  )
| project TimeGenerated, Computer, RenderedDescription
```

## Escalation Criteria
Escalate immediately to **Tier 2 / Incident Response (P1/Critical)** if:
- Real-time protection was disabled by an interactive non-administrative or compromised admin account.
- New executables or scripts were dropped and executed while Defender was disabled.
- Follow-on shadow copy deletion (T1490) or mass file encryption (T1486) is detected.

## Known False Positives
- Developers or system administrators configuring temporary exclusions for performance-sensitive compiling tasks (must be verified against authorized change request tickets).
