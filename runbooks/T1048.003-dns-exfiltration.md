# Runbook: Exfiltration Over Alternative Protocol via DNS Tunneling — T1048.003

## Alert Summary
This alert triggers when an outbound socket connection on destination port 53 (DNS) is initiated directly by a scripting engine, shell interpreter, or LOLBin (e.g. `powershell.exe`, `pwsh.exe`, `cmd.exe`, `certutil.exe`, `rundll32.exe`, `cscript.exe`, `wscript.exe`). In legitimate Windows enterprise environments, all standard DNS name resolution is delegated to the Windows DNS Client service (`svchost.exe -k NetworkService`). Direct socket connections to external port 53 by non-DNS system processes are a hallmark indicator of DNS tunneling, C2 beaconing, or data exfiltration over encoded DNS queries (TXT, A, AAAA, CNAME records).

## Immediate Triage Steps
1. **Identify Initiating Binary and Remote IP**: Extract `InitiatingProcessFileName`, `ProcessCommandLine`, `DestinationIp`, and `DestinationPort` (53). Check whether the remote destination IP is an authorized corporate recursive DNS resolver or an unmanaged public / attacker-controlled external nameserver.
2. **Inspect Query Payloads and Volume**: Query DNS client query logs or firewall/proxy logs for high-frequency or high-entropy subdomain requests generated by the host (e.g. Base64/Hex labels prepended to target domains: `[random-string].attacker-c2.com`).
3. **Correlate with Parent Process**: Trace the parent process tree of the executing script/LOLBin. Was it launched from an interactive user session, task scheduler, Office macro, or web server?
4. **Assess Potential Stolen Data**: Review file access activity (`FileRead`, Sysmon EID 11) by the initiating process immediately preceding the network activity to identify sensitive documents, credentials, or archives staged for exfiltration.
5. **Immediate Containment**: Disconnect the host from the network. Block the external destination IP / nameserver domain on perimeter firewalls and egress DNS filters.

## Investigation Queries
```kql
// Identify non-standard processes opening outbound connections on port 53
DeviceNetworkEvents
| where Timestamp between (datetime({AlertTime}) - 30m .. datetime({AlertTime}) + 10m)
| where DeviceName == "{DeviceName}"
| where RemotePort == 53
| where InitiatingProcessFileName has_any (
    "powershell.exe", "pwsh.exe", "cmd.exe", "certutil.exe",
    "rundll32.exe", "cscript.exe", "wscript.exe"
  )
| project Timestamp, DeviceName, InitiatingProcessFileName, InitiatingProcessCommandLine, RemoteIP, RemotePort, RemoteUrl
```

## Escalation Criteria
Escalate immediately to **Tier 2 / Incident Response (P1/Critical)** if:
- High frequency or large volume of subdomains with high entropy or encoded strings are observed.
- Destination IP is located in an untrusted geolocation or recognized bulletproof hosting infrastructure.
- Activity follows unauthorized access to sensitive file shares, databases, or local credential stores.

## Known False Positives
- Specialized network diagnostic scripts (e.g., custom PowerShell scripts executing `Resolve-DnsName` or raw socket tests) run by authorized network engineers.
