# Runbook: Persistence via Windows Registry Run or RunOnce Autostart Key — T1547.001

## Alert Summary
This alert triggers when Sysmon Event ID 13 (`RegistryEvent: SetValue`) records modifications to Windows Registry Run or RunOnce autostart keys (`HKLM\Software\Microsoft\Windows\CurrentVersion\Run`, `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`). Threat actors (including LockBit, Conti, and Commodity malware loaders) modify these registry values to achieve persistent execution across system reboots or interactive user logon sessions.

## Immediate Triage Steps
1. **Identify Executable and Path**: Examine `Details` and `TargetObject` in Event ID 13. Is the binary located in a non-standard or writable directory (`C:\Users\Public\`, `C:\ProgramData\`, `%APPDATA%`, `%TEMP%`)?
2. **Review Initiating Process**: Inspect `Image` and `User` in Event ID 13. Did the change originate from `reg.exe`, `powershell.exe`, an untrusted installer, or an unknown parent process?
3. **Analyze Target Binary**: Locate the binary on disk. Check file creation timestamps, file hash, digital signature, and whether it matches authorized software.
4. **Inspect Correlated Network Activity**: Pivot to Sysmon Event ID 3 (`NetworkConnect`) on the host to check if the newly registered executable has initiated external C2 communication.
5. **Remediation**: Remove the rogue registry key value and isolate the host to prevent payload re-execution upon reboot.

## Investigation Queries
```kql
// Identify Registry Run/RunOnce key creation or modification
DeviceRegistryEvents
| where Timestamp between (datetime({AlertTime}) - 15m .. datetime({AlertTime}) + 15m)
| where RegistryKey has_any (
    @"Software\Microsoft\Windows\CurrentVersion\Run",
    @"Software\Microsoft\Windows\CurrentVersion\RunOnce"
  )
| where not(RegistryValueData has_any ("Program Files", "System32", "SysWOW64"))
| project Timestamp, DeviceName, ActionType, RegistryKey, RegistryValueName, RegistryValueData, InitiatingProcessFileName
```

## Escalation Criteria
Escalate to **Tier 2 / Incident Response (P2/High)** if:
- Registry value points to a binary in temporary or public directories (`C:\Users\Public\`, `%TEMP%`).
- Value was written by a command-line script interpreter or living-off-the-land binary.
- Correlated C2 network beacons or credential access attempts are detected on the host.

## Known False Positives
- Enterprise software installers registering tray applications or updater components during approved software deployment.
- Antivirus / EDR agents writing authorized startup entries.
