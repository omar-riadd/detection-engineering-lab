# Runbook: Remote Thread Injection into System Processes (Process Hollowing) — T1055.012

## Alert Summary
This alert triggers when Sysmon Event ID 8 (`CreateRemoteThread`) detects a thread created in a core system process (e.g., `svchost.exe`, `notepad.exe`, `explorer.exe`) by an untrusted source process (`rundll32.exe`, `cmd.exe`, `powershell.exe`). This is a hallmark indicator of process hollowing or remote thread injection, allowing malware to execute arbitrary payloads from within the security context of a legitimate system binary.

## Immediate Triage Steps
1. **Analyze Source and Target**: Identify the injecting process (`SourceImage`, `SourceProcessId`) and the injected host (`TargetImage`, `TargetProcessId`).
2. **Inspect Start Address & Function**: Review `StartAddress` and `StartFunction`. Unbacked memory allocations (addresses outside valid DLL modules) indicate injected shellcode.
3. **Capture Injected Process Memory**: Take a memory dump of the target process using `ProcDump` or live forensic tools to inspect injected memory segments (look for `PAGE_EXECUTE_READWRITE`).
4. **Trace Injection Source Origin**: Review how the source process was spawned, including its command line, user context, and initial payload on disk.
5. **Isolate Affected Host**: Because process hollowing typically precedes active C2 establishment or lateral movement, prepare for network containment.

## Investigation Queries
```kql
// Query remote thread creation and correlated network connections
DeviceEvents
| where ActionType == "CreateRemoteThread"
| where Timestamp between (datetime({AlertTime}) - 5m .. datetime({AlertTime}) + 15m)
| where DeviceName == "{DeviceName}"
| project Timestamp, DeviceName, InitiatingProcessFileName, FileName, AdditionalFields
```

## Escalation Criteria
Escalate immediately to **Tier 2 / Incident Response (P1/Critical)** if:
- Remote thread creation originates from an untrusted user process into `svchost.exe` or `lsass.exe`.
- The target system process establishes network connections on non-standard ports or unclassified external IPs.
- Suspicious named pipes or secondary child processes are spawned by the target.

## Known False Positives
- EDR or anti-malware software performing in-process inspection or thread interception.
- Application performance monitoring tools or developer debuggers attached to running services.
