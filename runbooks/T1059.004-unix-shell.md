# Runbook: Interactive Reverse Shell Execution via Common Utilities — T1059.004

## Alert Summary
This alert triggers when interactive Unix shell processes (`bash`, `sh`, `nc`, `python`, `perl`) execute commands establishing network socket redirections (e.g. `/dev/tcp/`, `/dev/udp/`, `exec 5<>`, `pty.spawn`, `socket.socket`, `nc -e`). Adversaries frequently establish reverse shells as initial access or post-exploitation channels following web application exploitation or remote code execution.

## Immediate Triage Steps
1. **Analyze Command Line & Redirection**: Extract the remote IP and destination port from the command line (e.g., `/dev/tcp/<IP>/<PORT>`).
2. **Determine Parent Process**: Identify which process spawned the shell (e.g., `apache2`, `nginx`, `php-fpm`, `tomcat`, or unexpected system daemons).
3. **Verify Active Network Connections**: On the endpoint, check active network sockets using `ss -antp` or auditd network telemetry to confirm whether the TCP session is active.
4. **Inspect User Context**: Check if the command ran under a service account (e.g., `www-data`, `nobody`) or a privileged user (`root`).
5. **Containment Action**: If confirmed unauthorized, isolate the host and terminate the process tree (`pkill -P <PID>`).

## Investigation Queries
```kql
// Pivot on Unix shell executions and outbound network activity
DeviceProcessEvents
| where Timestamp between (datetime({AlertTime}) - 15m .. datetime({AlertTime}) + 15m)
| where DeviceName == "{DeviceName}"
| where FileName in~ ("bash", "sh", "dash", "nc", "ncat", "python", "python3", "perl")
| where ProcessCommandLine has_any ("/dev/tcp/", "/dev/udp/", "pty.spawn", "socket.socket", "-e /bin/bash", "-e /bin/sh")
| project Timestamp, DeviceName, AccountName, InitiatingProcessFileName, FileName, ProcessCommandLine
```

## Escalation Criteria
Escalate to **Tier 2 / Incident Response** if:
- A reverse shell was initiated from a web service account (`www-data`, `nginx`, `tomcat`).
- The shell establishes outbound TCP communication to external, unsanctioned IP addresses.
- Subsequent post-exploitation commands (enumeration, privilege escalation, SSH key installation) are observed.

## Known False Positives
- Authorized penetration testing, red teaming, or CTF lab exercises.
- Rare custom administrative diagnostic scripts using network redirection (should be converted to secure SSH or API automation).
