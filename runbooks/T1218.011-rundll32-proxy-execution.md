# Runbook: Suspicious Rundll32 Execution from Writable User Path — T1218.011

## Alert Summary
This alert triggers when `rundll32.exe` is executed with command-line arguments pointing to dynamic link libraries (DLLs) residing in user-writable paths (`C:\Users\Public\`, `\AppData\`, `\Temp\`, `\Downloads\`). Adversaries abuse this built-in signed binary (LOLBin) to proxy the execution of unapproved or malicious code, bypassing binary allowlisting and execution policies.

## Immediate Triage Steps
1. **Examine Target DLL**: Identify the DLL file path and export function specified in the `CommandLine` of `rundll32.exe`.
2. **Review Parent Process**: Determine which process spawned `rundll32.exe` (e.g., `cmd.exe`, `powershell.exe`, `wscript.exe`, or scheduled task).
3. **Capture DLL Binary**: Hash the target DLL (SHA-256) and determine whether the file is digitally signed by a trusted vendor.
4. **Inspect Child Processes & Network**: Identify child processes spawned by `rundll32.exe` or network connections established by the DLL.
5. **Analyze Process Memory**: Check if `rundll32.exe` exhibits signs of memory injection or thread creation into other processes.

## Investigation Queries
```kql
// Trace rundll32 network activity and child process lineage
DeviceProcessEvents
| where Timestamp between (datetime({AlertTime}) - 5m .. datetime({AlertTime}) + 30m)
| where DeviceName == "{DeviceName}"
| where InitiatingProcessFileName =~ "rundll32.exe" or FileName =~ "rundll32.exe"
| project Timestamp, DeviceName, FileName, ProcessCommandLine, InitiatingProcessFileName, InitiatingProcessCommandLine
```

## Escalation Criteria
Escalate to **Tier 2 / Incident Response** if:
- Target DLL is unsigned, packed, or located in a temporary staging path.
- `rundll32.exe` initiates outbound network connections to foreign or suspicious IP addresses.
- Subsequent credential dumping (LSASS access) or injection attempts are detected.

## Known False Positives
- Legitimate software installers or auto-updaters unpacking temporary DLLs into `AppData\Local\Temp` and executing registration routines.
- Specialized enterprise business hardware drivers with registration steps during first launch.
